Use this body only when `Track` is `process`.

## Where it fits

One of: `discover`, `specify`, `implement`, `review`, `verify`, `context`.

## Figure

Prefer a caption that describes a workflow, system, or pipeline overview. Use `![figure](url)`. If none matches, omit the image.

## Score

Weight these four axes equally, about 2.5 points each:

1. Process relevance — organizing development with AI.
2. Actionability — a practice, loop, or artifact this team can adopt.
3. Evidence — a benchmark, user study, or ablation, not only a demo.
4. Transfer — works outside the authors' own scaffold, in an existing repo with a spec and review.

Bands: 9–10 changes the loop this month. 7–8 is worth reading this week. 5–6 is adjacent. 3–4 is weak. 1–2 is off topic.
