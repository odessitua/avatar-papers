# Track: feature

Use this body only when `Track` is `feature`.

## Where it fits

One of: `charts`, `text-motion`, `screen-video`, `gui-agent`.

## Figure

Prefer a pipeline overview. If none exists, use one representative output example. Use `![figure](url)`. If neither exists, omit the image.

## Score

Weight these four axes equally, about 2.5 points each:

1. Feature relevance — chart generation, kinetic text, screen or demo video, or a GUI agent.
2. Novelty — a new approach, representation, or interaction.
3. Result quality — clearly better than the previous best, stated in plain language.
4. Product integrability — structured or editable output a language model can drive, at a latency the product can use.

Bands: 9–10 is worth trying in the product this month. 7–8 is worth reading this week. 5–6 is adjacent. 3–4 is weak. 1–2 is off topic.

## Body

Emit these headings and no others from this track:

## Capability

What the end user gets.

## Pipeline

Input, models, and output, in order.

## Output and integration

Output format (SVG, JSON, canvas, video), whether the result stays editable, and whether an API language model can drive it.

## Evaluation

Benchmarks or studies, and where the method wins or falls short.

## Competitors

Two or three closest systems. One sentence each on the difference.

## Latency and cost

Inference time, hardware, and whether it can run interactively.
